django-auth-tools

A Django middleware that redirects all unauthenticated requests to the login page — unless the view explicitly opts out.

Try Protected Page Try Public Page

How It Works

1. Middleware Intercepts

LoginRequiredMiddleware checks every incoming request. If the user is not authenticated, it redirects to LOGIN_URL.

2. Opt-Out for Public Views

Use @no_login_required (FBV) or NoLoginRequiredMixin (CBV) to mark views as publicly accessible.

3. Redirect with ?next=

The original URL is preserved via the next query parameter, so users return to their intended destination after login.

Setup

settings.py 
MIDDLEWARE = [
    ...
    "django.contrib.auth.middleware.AuthenticationMiddleware",
    "django_auth_tools.middleware.LoginRequiredMiddleware",
    ...
]

LOGIN_URL = "/accounts/login/"
views.py 
# Function-Based View
from django_auth_tools.decorators import no_login_required

@no_login_required
def public_page(request):
    ...

# Class-Based View
from django_auth_tools.mixins import NoLoginRequiredMixin

class PublicPage(NoLoginRequiredMixin, TemplateView):
    template_name = "public.html"

Components

Component Type Description
LoginRequiredMiddleware Middleware Intercepts all requests; redirects unauthenticated users to LOGIN_URL.
@no_login_required Decorator Marks a function-based view as publicly accessible (no login needed).
NoLoginRequiredMixin Mixin Marks a class-based view as publicly accessible (no login needed).
