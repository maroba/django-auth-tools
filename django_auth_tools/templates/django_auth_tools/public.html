Public Page

This view uses NoLoginRequiredMixin to opt out of the LoginRequiredMiddleware.

Class-Based View (Mixin) 
from django_auth_tools.mixins import NoLoginRequiredMixin

class PublicView(NoLoginRequiredMixin, TemplateView):
    template_name = "public.html"

The mixin sets no_login_required = True on the view class. The middleware detects this attribute and skips the redirect.

Function-Based View (Decorator) 
from django_auth_tools.decorators import no_login_required

@no_login_required
def public_page(request):
    return render(request, "public.html")

The decorator sets no_login_required = True on the wrapped function. Works the same way for function-based views.
