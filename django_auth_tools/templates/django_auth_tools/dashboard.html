Why This Page Is Protected

The DashboardView is a plain TemplateView — it does not use NoLoginRequiredMixin or @no_login_required. 

class DashboardView(TemplateView):
    template_name = "django_auth_tools/dashboard.html"

Because no opt-out is present, LoginRequiredMiddleware redirects unauthenticated users to the login page automatically.

Protected by Default

With the middleware active, every view is protected unless explicitly marked as public.
